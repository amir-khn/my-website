About Us

TravelBloom is a travel recommendation website created to help users explore inspiring destinations, including scenic beaches, historic temples, and notable countries around the world.

Our mission is to make discovering new places simple, visual, and helpful for travelers planning their next trip.

Guidance & Instructions for Team Members

Team members contributing to this project should follow these guidelines:

  • Use Consistent File Names: Keep filenames lowercase (index.html, about.html, contact.html, and style.css) in the root folder.
  • Check Links & Images: Confirm that navigation links work across pages and every destination card includes a working image URL and alt text.
  • Test Features Before Submitting: Test the Search and Clear buttons with keywords like beach, temple, and country, and verify the live GitHub Pages site.
  • Document Changes Clearly: Use clear commit messages when updating files in GitHub.
