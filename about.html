About Us

TravelBloom is a travel discovery and destination recommendation platform built to help travelers explore notable beaches, historic temples, and diverse countries around the world. Our goal is to make trip planning clear, inspiring, and easy to browse.

Guidance & Instructions for Team Members

Every contributor and team member working on this project should follow these standard practices:

  • Keep File Names & Links Consistent: Use lowercase filenames (index.html, about.html, contact.html) at the repository root so relative links work reliably on GitHub Pages.
  • Commit Clearly & Test Before Publishing: Write clear commit messages and verify pages in a browser after GitHub Pages finishes deploying.
  • Maintain Clean, Readable Markup: Keep HTML tags properly closed, use descriptive alt text on images, and test interactive buttons.
  • Coordinate Updates: Share major layout, data, or navigation changes with the team so all pages stay in sync.
